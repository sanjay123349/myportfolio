# Sanjay Kumar Tripathi — Portfolio Website

## Files
- `index.html` — page content and sections
- `style.css` — responsive design, layout, animations, dark/light themes
- `script.js` — mobile menu, theme toggle, scroll reveal, copy-email action
- `resume.pdf` — your résumé used by the Download résumé button

## Run locally
1. Extract the ZIP.
2. Keep `index.html`, `style.css`, `script.js`, and `resume.pdf` in the same folder.
3. Open `index.html` in your browser. For editing, open the folder in VS Code and use Live Server.

## Before publishing
- Verify the resume's details and links.
- The portfolio uses Lucide icons and Google Fonts via CDN, so those assets need an internet connection.
- To deploy, upload the files to GitHub Pages, Netlify, or Vercel static hosting.
- The contact action opens the visitor's email app; it is not a server-backed contact form.
